# QuantumCare / MediCare Frontend

Unified Healthcare Platform frontend built with React, Vite, and React Router.

## Features
- **Patient Portal**: Appointments, records, medicines, schemes, and emergency features
- **Doctor Portal**: Patient queue, consultations, medical records, prescriptions, and messages
- **Hospital Portal**: Department overview, OPD management, staff, doctors, and reports
- **Kiosk Terminal**: Self-service check-in and vital intake terminal
- **Unified Authentication**: Multi-role login with Aadhaar / phone OTP and password support

## Quick Start

```bash
# Install dependencies
npm install

# Start local dev server (default http://localhost:5173)
npm run dev

# Build for production
npm run build
```
